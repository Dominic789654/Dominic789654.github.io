Serving DiffAdapt via Decision APIs

Research note · draft · Xiang Liu · Oct 2026

Test-time compute—chain-of-thought, long thinking traces, search—has become a first-class lever for LLM reasoning (Wei et al., 2022; Snell et al., 2024; Weng, 2025). More thinking is not uniformly better: models overthink easy problems, burn tokens on traces that do not change the answer, and create stragglers under shared serving (Sui et al., 2025; Li et al., 2025).

Two recent threads suggest a cleaner control loop. DiffAdapt allocates Easy / Normal / Hard inference strategies from a lightweight probe on prefill hidden states (Liu et al., 2025). Decision interfaces—TypeSafe’s System One / Jev (TypeSafe; JevServe blog) and SGLang’s /v1/decisions (plus /v1/systemone) (SGLang docs)—turn typed questions into label probabilities with no text generation. This note sketches how those pieces fit. No new experiments are claimed; open directions only.

What DiffAdapt already shows

Across reasoning models, token-level entropy of traces forms a U-shape over problem difficulty: high entropy on easy items despite high accuracy (overthinking), low entropy in a mid band, high entropy again on hard items (about 22–25% entropy drop from easy to mid). DiffAdapt maps that onto three fixed strategies (prompt + temperature + max tokens) via a small MLP on the last-layer prefill state—no LLM fine-tune. On five models and eight benchmarks it matches or improves accuracy while cutting tokens by up to 22.4% (Liu et al., 2025; ICLR 2026).

Limitations the paper flags: routing is prefill-only; strategy labels come from a proxy sampling protocol; aggressive Easy budgets can truncate rare cases (~2% truncation in their LLM-as-judge check).

What decision APIs change

Per SGLang’s decision-models docs (checked Oct 2026):

  • POST /v1/decisions scores choice / score / yes_no from next-token scores at answer labels; completion tokens = 0; returns probabilities, and label_mass (full-vocab mass on the offered labels). Thinking is forced off.
  • POST /v1/systemone mirrors the System One request shape (noul / choice / score) for TypeSafe-compatible clients; for ordinary chat models it uses the same scoring path. Decision checkpoints (e.g. Jev-style) use their own calibrated path.
  • Docs emphasize: returned probabilities are not calibrated correctness—validate thresholds on labeled data.

TypeSafe: System One models return typed decisions (Choice / Score / Noul) rather than free text; Jev is their flagship. JevServe reports Jev stronger on content judgments than on predicting other systems’ behavior, and that in their H200 ShareGPT replay, length-aware scheduling with Jev raised SLO attainment sharply (blog summary: 75%→99%; P90 TTFT 8.3 s→0.17 s under the reported load). Not re-run here.

Engine asymmetry: SGLang documents /v1/decisions today; a portable DiffAdapt×decision stack is SGLang-native unless the surface is ported.

The missing middleware

DiffAdapt decides how hard to think. Decision APIs decide structured facts about the request at admission (and, in principle, mid-generation via /v1/score). Serving still mostly uses fixed rules for priority, max tokens, speculative depth, and KV reservation—despite evidence that reasoning workloads straggle when difficulty is unmodeled (Li et al., 2025).

Hypothesis: pack Easy/Normal/Hard (plus “think?”, expected length) as one decision call; feed the result into the scheduler—DiffAdapt’s control signal without a custom probe path, or as a calibrated complement to the probe.

Open directions (not yet run)

1. Decision-native DiffAdapt

Replace or ablate the MLP probe with /v1/decisions: choice over Easy/Normal/Hard, optional score for length, yes_no for thinking. Gate with label_mass (low mass → escalate to Normal). Reuse DiffAdapt Stage-1 labels where available.

2. Difficulty-aware serving

Map decision outputs → max_tokens, think on/off, speculative aggressiveness, KV / priority. Evaluate accuracy, goodput, P90 TTFT, peak KV—aligned with JevServe’s length-prediction story and DiffAdapt’s token savings (Li et al., 2025).

3. Online re-decide

After k tokens or an entropy spike, re-ask continue / early-stop / upgrade (prefer Easy→Normal upgrades). Compare to early-exit CoT (Yang et al., 2025).

4. Bake-off

Probe vs chat-model /v1/decisions vs Jev on the same difficulty labels, especially OOD (math → MMLU-Pro / GPQA).

If one paper: Serving DiffAdapt via Decision APIs—adaptive strategies + admission control on a standardized decision surface.

Caveats

  • Do not treat label_mass / System One confidence as calibrated correctness (SGLang; TypeSafe).
  • Mid-decode decisions must fit engine latency budgets; gateway-time decisions are the easy win today (JevServe).
  • Claims about DiffAdapt numbers and JevServe SLO figures are from the cited sources only; this note adds no new measurements.
